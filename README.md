# Escolha uma emoção !

"Escolha-uma-emocao" é um projeto desenvolvido em sala de aula, durante meu aprendizado na Instituição Senac. Esse foi meu primeiro projeto em React sem assistência de instrutores.

## Objetivo

Criar uma página onde o usuário possa escolher uma emoção no qual se identifica, a página deve ser responsiva tanto para dispositivos mobiles quanto para micro-computadores

## Tecnologias Utilizadas

- [React](https://reactjs.org/)
- [Node.js](https://nodejs.org/)
- [HTML5](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/HTML5)
- [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS)

## Como Executar

### Requisitos:
- [Node.js](https://nodejs.org/pt)
- [Visual Studio Code](https://code.visualstudio.com/)

### Passo-a-Passo
1 - pressione CTRL+SHIFT+' para abrir um novo terminal <br/>
2 - digite "git clone https://github.com/Thug-Okami/Escolha-uma-emocao/" no terminal <br/>
3 - em seguida, digite "cd Escolha-uma-emocao" no terminal <br/>
4 - após isso, digite "npm i" no terminal <br/>
5 - finalizando agora, clique com botão esquerdo do mouse enquanto segura CTRL, no link que apareceu no terminal e em seguida, verifique a aba que abriu em seu navegador <br/>
